job-hunter-toolkit

Search a nightly snapshot of postings crawled from thousands of company job boards. The query engine runs entirely in your browser — no backend, no account, no tracking.

    Every number on this page comes from the snapshot named in the banner — nothing here is live, and postings may have closed since the crawl. Built from job-hunter-toolkit; the crawler, the file format and this page's query engine are the same Go code the CLI runs.
